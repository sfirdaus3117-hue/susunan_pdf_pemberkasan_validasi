# Website Susunan Pemberkasan Staf Personel

## Isi folder
- `index.html` — website daftar dokumen dengan tema militer dan menu klik-buka.
- Tambahkan file PDF sumber ke folder ini dengan nama persis `RINDRA AFRILYANSYAH.pdf`.

## Menjalankan di komputer/HP
Buka `index.html` menggunakan browser. Agar tombol menuju halaman PDF berfungsi, letakkan PDF di folder yang sama.

## Mengunggah ke GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah `index.html` dan PDF ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/root`, lalu tekan **Save**.
6. Tunggu proses publikasi, lalu buka alamat GitHub Pages yang ditampilkan.

## PENTING — keamanan dokumen pribadi
PDF ini berisi data identitas dan dokumen pribadi. Repository GitHub publik dapat diakses siapa saja. Jangan unggah PDF asli ke repository publik. Gunakan repository **Private**, atau buat salinan PDF yang sudah menyamarkan data sensitif sebelum dipublikasikan. Periksa juga pengaturan akses GitHub Pages karena konten situs dapat menjadi publik.
